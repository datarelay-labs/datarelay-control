# CHATGPT-DATA-RELAY-GUARDRAIL
Version 1.0

Purpose

이 문서는 ChatGPT가 Data Relay 프로젝트에서
설계 제안, 우선순위 판단, Cursor 프롬프트 생성 시
반드시 따라야 하는 행동 규칙이다.

이 문서는 ChatGPT 행동을 제한하기 위한 문서이며,
제품 설계 문서가 아니다.

==================================================
Current Goal
==================================================

현재 목표

OSS v1.0 Release

현재 단계

M20.4.1 Release Blocker Cleanup

다음 단계

OSS v1.0 RC

그 다음

OSS v1.0 GA

그 이후

M21 AI Gateway

==================================================
Priority Order
==================================================

항상 아래 우선순위를 따른다.

1. Release Blocker
2. Runtime
3. Data Control
4. Delivery
5. Governance
6. AI Gateway
7. Enterprise Features

==================================================
Governance Freeze Rule
==================================================

다음 영역은 이미 충분히 구현된 것으로 간주한다.

- Policy
- Approvals
- Violations
- Quarantine
- Replay
- Audit
- Notifications
- RBAC
- Operations

새로운 Governance 기능은 제안 금지.

예외

- 버그 수정
- 성능 개선
- UI 개선
- 보안 수정

==================================================
Release Blocker Rule
==================================================

다음 중 하나라도 존재하면

- Backend Test Failure
- Frontend Test Failure
- Build Failure
- Runtime Failure
- Installation Failure

새 기능 제안 금지.

문제 해결을 우선 제안한다.

==================================================
Next Step Rule
==================================================

사용자가

"다음은?"
"다음 단계는?"
"무엇을 해야 하지?"

라고 질문하면

반드시 아래 순서로 판단한다.

1. 현재 Milestone 미완료 항목
2. Release Blocker
3. 현재 WBS
4. 다음 WBS

새로운 카테고리 생성 금지.

==================================================

==================================================
Architecture Drift Rule
==================================================

다음 방향으로 프로젝트를 이동시키는 제안 금지.

==================================================
Mandatory Check
==================================================

새 기능 제안 전 반드시 판단

[WBS 영역]
Runtime / Data Control / Delivery / Governance / AI Gateway

[현재 마일스톤 포함 여부]
YES / NO

[OSS 필수 여부]
YES / NO

[Scope Risk]
LOW / MEDIUM / HIGH

[제안 가능 여부]
ALLOW / REJECT

ALLOW가 아니면 제안 금지.

==================================================
Definition Of Done
==================================================

- Code Complete
- Tests Pass
- API Complete
- UI Complete
- RBAC Applied
- Documentation Updated
- No Release Blocker

위 조건 미충족 시
완료로 간주하지 않는다.
