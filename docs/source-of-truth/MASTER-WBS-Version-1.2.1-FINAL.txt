# MASTER-WBS
Version 1.2.1

==================================================
WBS Governance Rule
==================================================

본 문서는 PRODUCT-CHARTER Version 1.2.1을 따른다.

PRODUCT-CHARTER는 Source Of Truth 이다.

WBS는 PRODUCT-CHARTER와 충돌할 수 없다.

--------------------------------------------------

PRODUCT-CHARTER에 없는 기능은

WBS에 포함될 수 없다.

--------------------------------------------------

특히 아래 영역은

현재 제품 범위 밖이다.

- SSO
- SAML
- OIDC
- Enterprise IAM
- SCIM
- Identity Federation
- User Provisioning

해당 기능은

Data Relay Control 범위 밖이며

별도 제품 영역으로 관리한다.

--------------------------------------------------

Data Relay Control의 현재 제품 범위는

Phase A Foundation
Phase B Data Control Runtime
Phase C Governance
Phase D OSS Release / closure

뿐이다.

Phase E AI Gateway 와
Phase F Enterprise Edition 은

Data Relay Control 현재 제품 범위가 아니며

Control 완료도 / 릴리스 readiness /
Control delivery backlog 에 포함되지 않는다.

--------------------------------------------------

Data Relay는

Enterprise Data Control Gateway이다.

Identity Platform이 아니다.
