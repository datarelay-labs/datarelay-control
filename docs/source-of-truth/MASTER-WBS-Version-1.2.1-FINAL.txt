==================================================
WBS Governance Rule
==================================================

본 문서는 PRODUCT-CHARTER Version 1.2.1을 따른다.

PRODUCT-CHARTER는 Source Of Truth 이다.

WBS는 PRODUCT-CHARTER와 충돌할 수 없다.

--------------------------------------------------

PRODUCT-CHARTER에 없는 기능은

WBS에 포함될 수 없다.

--------------------------------------------------

특히 아래 영역은

현재 제품 범위 밖이다.

- SSO
- SAML
- OIDC
- Enterprise IAM
- SCIM
- Identity Federation
- User Provisioning

해당 기능은

Data Relay Control 범위 밖이며

별도 제품 영역으로 관리한다.

--------------------------------------------------

Data Relay Control의 현재 제품 범위는

Phase A Foundation
Phase B Data Control Runtime
Phase C Governance
Phase D OSS Release / closure

뿐이다.

Phase E AI Gateway 와
Phase F Enterprise Edition 은

Data Relay Control 현재 제품 범위가 아니며

Control 완료도 / 릴리스 readiness /
Control delivery backlog 에 포함되지 않는다.

--------------------------------------------------

Data Relay는

Enterprise Data Control Gateway이다.

Identity Platform이 아니다.

P0-UX-01 — Data Flows Operational Workspace (Routes overview successor)
- Current Source/Stream -> Route Processing -> Destination topology first.
- Actual per-edge EPS, success/failure/retry, health, activity and selected
  route inspector using existing Runtime Snapshot; capacity only if configured.
- Distinguish Source ingest vs Route egress and sent vs acknowledged.
- Preserve filtered expert catalog/table and authorized Route Edit deep links.

P0-UX-02 — New Data Flow guided onboarding
- Reuse/select Connector; create missing Connector without losing Wizard draft.
- Source test/sample/record path/checkpoint; destination selection or contextual
  destination creation; return to draft after each prerequisite.
- Route Processing per destination, deploy and verify actual runtime results.
- Reuse canonical state/persistence/gates and RBAC, do not auto-activate.

P0-UX-03 — Navigation and page ownership
- Data Flows for operation and lineage; Streams for collection/execution;
  Connections for reusable Connectors and Destinations; Governance and
  Administration remain role-constrained.
- Global "New Data Flow"; retain legacy routes and expert editing URLs.
- Remove redundant Stream/Route onboarding controls only when owner-facing
  replacement is working, not by deleting necessary configuration workflows.

P0-UX-04 — Operational truth corrections
- Explain "offline/local draft" accurately when API state is unavailable.
- No generic Header Healthy badge based on configuration page or missing data.
- No fake delivery/acknowledgment, capacity/EPS or preview-persistence claims.

P1-UX-05 — Progressive operator/expert modes and accessibility
- Scale topology via grouping/filter/search/select; maintain keyboard-accessible
  table/list fallback and mobile narrow-view layout.
- Contextual help and working sample path remain applicable.
