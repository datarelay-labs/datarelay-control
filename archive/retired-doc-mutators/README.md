# Retired documentation mutators

These one-shot scripts are retained only for historical traceability.

They predate the current Source-of-Truth authority model and append policy directly into historical master-design / constitution / spec-index files. Running them would reintroduce duplicated or superseded authority.

Do not run these scripts. Make current documentation/specification changes through the canonical files identified by `docs/architecture/source-of-truth-index.md`.
